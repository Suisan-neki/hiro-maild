無料で、ブラウザーから同期する

常時稼働サーバーや有料ディスクは不要です。画面を開いてボタンを押したときに、大学の受信トレイから自分のGmailへ転送します。

初回のみGoogleとMicrosoftのOAuthアプリ登録が必要です。画面に入力するのは公開client IDだけです。client secretやパスワードは入力しません。大学の管理者同意が必要か、実アカウントでの転送は未確認です。

1. Googleのアプリを登録

  1. Google Cloud Consoleでプロジェクトを作り、Gmail APIを有効にします。
  2. Google Auth PlatformでAudienceをExternalに設定。Testingなら自分のGmailをテストユーザーに追加します。
  3. Data Accessに openid、email、https://www.googleapis.com/auth/gmail.send を登録します。
  4. OAuth clientを Web application で作り、Authorized JavaScript originsにこの画面のoriginを登録します。標準公開先では https://suisan-neki.github.io です。/hiro-maild/は付けません。
  5. …apps.googleusercontent.com というclient IDを画面へコピーします。client secretとGoogle callback設定は使いません。

個人の確認済み@gmail.comを使います。他の人へ配布する場合にはGoogleの同意・審査条件を確認してください。

2. Microsoftのアプリを登録

  1. Microsoft Entra管理センター → App registrationsで、自分が管理できるアプリを作ります。別テナントで登録する場合は「任意の組織ディレクトリのアカウント」を選びます。
  2. Authentication → Add a platform → Single-page application (SPA)を選び、redirect URIに https://suisan-neki.github.io/hiro-maild/redirect.html を登録します。Webプラットフォームとsecretは使いません。
  3. API permissions → Microsoft Graph → Delegated permissions で User.Read と Mail.Read を追加します。書込みや送信権限は不要です。
  4. OverviewのApplication (client) IDを画面へコピーします。

大学がアプリ連携やユーザー同意を禁止している場合、大学管理者の承認が必要です。アプリ登録ができない場合も管理者への相談が必要です。この制限を回避する機能はありません。

3. 接続して使う

  1. 普段使うブラウザーの通常ウィンドウで同期画面を開き、初回だけ両社の公開client IDを保存します。
  2. Gmailと大学のMicrosoftアカウントにログインします。
  3. 初回だけ「今から」または過去の日時を指定し、開始位置を保存します。開始日時とアカウントは履歴に固定されます。
  4. 「対象を確認（送信なし）」を押して件数や件名を確認します。
  5. 「同期して転送」を押し、処理終了まで画面を開いておきます。次回はログインしてこのボタンを押すだけです。

1回に最大10ページ・50通を処理します。大量の過去分を指定した場合は、初回の対象確認を繰り返してから転送してください。画面を閉じると停止し、次の手動同期までGmailには届きません。大学側を既読化・移動・削除しません。同期前に受信トレイから移動・削除したメールは取得できません。

保持する内容と再試行

元の本文・HTML・添付・CIDをMIMEごとコピーし、全原本もoriginal.emlとして添付します。外側の差出人・宛先は個人Gmail、日時は転送時刻です。元送信者・日時は転送情報と原本に残ります。原本18 MiB・組立後34 MiBを超えるメールは保留し、添付を勝手に省略しません。

通信断や画面終了で送信結果が分からない場合は、自動再送しません。履歴のin:anywhere rfc822msgid:…をGmailで検索し、届いていないことを確認してから再試行を予約してください。再送には重複リスクがあります。送信制限（429）は時間を置いて次回の手動同期で再試行します。

履歴は同じブラウザーに保存

別端末・別ブラウザー・プライベートウィンドウでは履歴が共有されません。サイトデータを消すと送信済みのメールを再送する可能性があります。履歴を失った場合はGmailを照合し、過去の開始日時を安易に再指定せず「今から」等を選んでください。バックアップ・端末間共有はありません。
